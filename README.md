# Midburn LED Statues

Four statues in an 8 m circle, covered in WS2812B LED strips and run as one show from a
single controller. You control it from a phone over the controller's own WiFi. No internet
is needed.

## System

![Four statues in a circle. The controller at statue 0 has a data cable to each of the others.](guide/img/overview.svg)

- One ESP32 running [WLED](https://kno.wled.ge), in the controller box at statue 0, drives
  all eight data channels: two per statue.
- Statue 0's strips connect to the controller box directly. Statues 1–3 get their two
  channels as RS-485 over one buried CAT5e cable each.
- Each box has its own 5 V 20 A PSU on mains. Only data and ground cross between statues.
- Each channel drives two chained strips, so each box has four LED exits.
- The controller runs its own WiFi access point at `http://4.3.2.1`. The password comes from
  the installation lead.
- The data cables are not Ethernet: never connect them to network equipment or PoE.
